   Snake Water Gun Game

A simple and interactive Snake Water Gun game built using HTML, CSS, and JavaScript.

The player chooses Snake, Water, or Gun, and the computer randomly selects its choice. The game determines the winner based on the classic Snake Water Gun rules.


## ✨ Features

* 🐍 Snake, 💧 Water, and 🔫 Gun choices
* 🤖 Random computer choice
* 🏆 Automatic winner detection
* 📊 Player, Computer, and Draw scores
* 🔢 Round counter
* 🔄 Restart game button
* ✨ Interactive button effects and animations
* 📱 Responsive design for mobile and desktop
* 🎨 Modern dark glassmorphism-style UI

## 🕹️ Game Rules

| Player      | Computer    | Result     |
| ----------- | ----------- | ---------- |
| 🐍 Snake    | 💧 Water    | Snake wins |
| 💧 Water    | 🔫 Gun      | Water wins |
| 🔫 Gun      | 🐍 Snake    | Gun wins   |
| Same choice | Same choice | Draw       |

### Example

If you choose:

**🐍 Snake**

and the computer chooses:

**💧 Water**

You win because **Snake beats Water**.
